The Problem

LLMs are probabilistic systems.

If your application depends on structured JSON generated by an LLM, you’ve introduced an invisible contract into your backend.

That contract can drift:

  • A model update subtly changes output shape
  • A prompt tweak alters field behavior
  • Temperature changes increase instability
  • Outputs pass basic tests but fail under repetition

Everything appears fine — until production breaks.

How Aicert Works

Aicert runs your structured prompts across defined test cases multiple times, then computes reliability metrics:

  • Schema compliance
  • Output stability across runs
  • Latency percentiles
  • Drift between configurations

You can define thresholds and enforce them in CI. 

pip install aicert
aicert ci aicert.yaml

FAQ

Do I need API keys?

For production evaluation, yes — Aicert runs against your configured LLM providers. It is designed to measure real system behavior under your actual configuration.

Is this only for agents?

No. It applies to any system that depends on structured output from an LLM.

What does Pro add?

Core measures reliability. Pro enforces it by locking baselines and failing CI when regressions occur.
